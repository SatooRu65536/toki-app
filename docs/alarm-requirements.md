# アラーム機能 要件定義

iPhone標準「時計」アプリのアラーム機能を、本アプリ(toki / Android・Jetpack Compose)で再現する。

## 1. 目的・スコープ

- iPhone標準の時計アプリ「アラーム」タブと同等の操作感・機能を提供する。
- 対象は **アラーム機能と、その拡張機能(N分後アラーム、N分後メディア停止)**。世界時計・ストップウォッチは対象外。
- 対象プラットフォーム: Android 8.0 (API 26) 以上。

## 2. 用語

| 用語 | 意味 |
|---|---|
| アラーム | 時刻・繰り返し等の設定を持つ1件のエントリ |
| 有効 / 無効 | トグルのON/OFF。ONのときのみ鳴動する |
| 鳴動 | 設定時刻に音・振動・通知でユーザーに知らせること |
| スヌーズ | 鳴動を一時停止し、一定時間後に再鳴動させること |
| N分後アラーム | 「今からN分後」を指定して1回だけ鳴らすアラーム。通常アラームと同じ鳴動・スヌーズの仕組みを使う |
| スリープタイマー | N分後に他アプリの音楽・動画などの再生を停止する機能 |

## 3. 機能要件

### 3.1 アラーム一覧画面

- 登録済みアラームを **時刻の昇順** で一覧表示する。
- 各行に以下を表示する。
  - 時刻(大きく表示。12/24時間表記は端末設定に従う)
  - 1行目: 時刻の右に「(スヌーズ N分)」または「(スヌーズ なし)」
  - 2行目: 繰り返し内容に続けて、該当する場合のみ「音なし」「バイブレーションなし」を全角スペース区切りで表示(例: 「明日　音なし　バイブレーションなし」)
  - 繰り返し内容(例: 「平日」「毎日」「月・水」。繰り返しなしは「今日」または「明日」)
  - 有効/無効トグル
- 無効のアラームは文字をグレーアウトする。
- トグル操作で即時に有効/無効を切り替え、スケジュールを更新する。
- 右上「+」ボタンで新規作成画面を開く。
- 左上「編集」ボタンで編集モードに入り、各行に削除ボタンを表示する(タップで編集画面へ遷移も可)。
- 行を左スワイプで削除できる。
- アラームが0件のときは空状態(「アラームはありません」等)を表示する。
- 次に鳴るアラームまでの残り時間を表示する(例: 「7時間23分後に鳴ります」)。トグル変更・追加時にトースト/スナックバーで表示してもよい。

### 3.2 アラーム作成・編集画面

| 項目 | 内容 | 初期値 |
|---|---|---|
| 時刻 | ホイール(ドラムロール)式のタイムピッカー。時・分。12時間表記時はAM/PM | 現在時刻 |
| 繰り返し | 日〜土の複数選択。未選択=1回のみ | なし |
| サウンド | 着信音の選択(端末の着信音/アラーム音から選択、試聴可)。「なし」を選ぶと無音(振動・通知のみ) | 既定のアラーム音 |
| バイブレーション | ON/OFF(鳴動時に振動するか) | ON |
| バイブレーションの種類 | 6種類から選択(標準 / 短く連続 / 長く / ハートビート / トントントン / SOS)。選択時に試し振動する。バイブレーションON時のみ表示 | 標準 |
| スヌーズ | 時刻ホイールの右側に配置した縦スクロール(ホイール)で選択。「なし」(=スヌーズOFF)または1〜15分。N分後モードでは同じホイールを単独で表示 | 9分 |

- 「キャンセル」で破棄、「保存」で確定する。
- 編集時は画面下部に「アラームを削除」ボタンを表示する。
- 保存時、アラームは自動的に有効状態になる。

### 3.3 鳴動

- 有効なアラームは設定時刻(秒は00)に鳴動する。
- 端末がスリープ中・アプリ終了中・ロック中でも鳴動する。
- 鳴動時の動作:
  - アラーム音をループ再生する(音量はアラーム音量に従う。サウンドが「なし」の場合は再生しない)。
  - 振動する(バイブレーションがONの場合のみ)。
  - 消灯中・ロック中は、フルスクリーンで鳴動画面を表示する(現在時刻・「スヌーズ」「停止」ボタン)。
  - 端末使用中(画面点灯かつロック解除済み)は、フルスクリーンではなく画面上部に出るヘッドアップ通知(スヌーズ/停止アクション付き)で知らせる。
- 「停止」で鳴動を止める。
  - 繰り返しなし: アラームを自動で無効にする。
  - 繰り返しあり: 次回の該当日にリスケジュールする。
- 「スヌーズ」(スヌーズONの場合のみ表示):
  - **設定した間隔(分)後** に再鳴動する(初期値9分、1〜15分、アラームごとに設定)。
  - スヌーズ中は通知に「スヌーズ中」と残り時間を表示する。
  - 回数制限なし。
- 操作されなかった場合、**1分間** 鳴動後に自動でスヌーズ(スヌーズOFFなら停止)する。

### 3.4 スケジューリング・永続化

- アラームは端末内に永続化する(現状の実装は SharedPreferences + JSON)。保存項目: ID、時、分、繰り返し曜日(ビットマスク等)、サウンドURI、バイブレーション有無・種類、スヌーズ有無・間隔、有効フラグ。
- 次回鳴動時刻を算出し、`AlarmManager.setAlarmClock()` で登録する(Doze中も正確に鳴らすため)。
  - 同時に登録できるのは「次に鳴る1件」のみでもよいが、全アラームを個別に登録してもよい(設計時に決定)。
- 次回時刻の算出ルール:
  - 繰り返しなし: 設定時刻が現在より未来なら今日、過去なら明日。
  - 繰り返しあり: 現在以降で最も近い該当曜日。
- 以下のタイミングで再スケジュールする。
  - 端末再起動(`BOOT_COMPLETED`)
  - アプリ更新(`MY_PACKAGE_REPLACED`)
  - 端末の時刻・タイムゾーン変更
  - アラームの追加・編集・削除・有効/無効切替
  - 鳴動完了後(繰り返しアラームの次回分)

### 3.5 N分後アラーム

「今からN分後」を指定して鳴らす、1回限りのアラーム。

- 画面下部のナビゲーションバー(「アラーム」「N分後」「スリープ」)の「N分後」タブから設定する。
  - 有効なN分後タイマーがない場合: 設定フォームを表示する。
  - 有効なN分後タイマーがある場合: 鳴動予定時刻と残り時間(カウントダウン)を表示し、「編集」「タイマーをキャンセル」ができる。
- 入力: N(分)。1〜180分。縦スクロールのホイールで指定し、スヌーズのホイールの隣に並べて配置する。
- 設定できるN分後アラームは **1つのみ**。新しく設定(または停止済みのものを再度ON)すると、既存のN分後アラームは置き換えられる(削除される)。
- 設定項目は通常アラームと共通: **サウンド、バイブレーション、スヌーズ(ON/OFF・間隔)**。
- 保存した時点を起点に、`現在時刻 + N分` を鳴動時刻として確定する(以後、端末時刻の変更で鳴動時刻はずらさない。絶対時刻で保持する)。
- 一覧画面では通常アラームと同じ一覧に混在表示する。
  - 時刻は鳴動予定時刻(例: 「7:35」)を表示し、補足に「N分後アラーム」と残り時間を表示する。
  - 有効/無効トグル、スワイプ削除、編集が可能。
- 鳴動・スヌーズ・自動停止の挙動は 3.3 と同一(スヌーズは設定した間隔、無操作1分で自動スヌーズ/停止)。
- 停止後は自動で無効にする(繰り返しはなし)。停止から24時間後に一覧から自動削除する。
- 再起動・時刻変更後も、確定済みの絶対時刻で再スケジュールする。すでに過ぎている場合は、再起動直後に即時鳴動する。
- 編集時にNを変更した場合は、**保存した時点から** N分後に再計算する。

### 3.6 N分後にメディア再生を停止(スリープタイマー)

就寝前に音楽や動画を流したまま眠っても、N分後に自動で再生が止まるようにする機能。

- 入力: N(分)。縦スクロールのホイールで 10 / 15 / 30 / 45 / 60 / 90 分のいずれかを選ぶ(これ以外の値は指定できない)。
- 開始・キャンセルは専用画面(またはアラーム一覧内の項目)から行う。実行中は残り時間をカウントダウン表示する(通知にも表示)。
- 時間が経過したら、端末で再生中の音声・動画(他アプリを含む)を停止する。
  - 実装方針: `AudioManager` で音声フォーカスを取得して他アプリの再生を中断させる、およびメディアキーイベント(`KEYCODE_MEDIA_PAUSE` / `KEYCODE_MEDIA_STOP`)を送出する。方式は検証して決定する(下記 未決事項)。
- 停止前のフェードアウト(最後の数十秒で音量を下げる)は、実現可能であればオプションとして提供する(初期値: OFF)。
- 同時に有効にできるスリープタイマーは **1つのみ**。新規開始時は既存のタイマーを置き換える。
- N分後アラームとは独立して動作する(併用可能。例: 30分後に再生停止、7時間後にアラーム)。
- 停止後、必要に応じて画面の消灯は行わない(端末の自動消灯に任せる)。
- 再起動・アプリ終了後もタイマーを継続する。再起動で継続できない場合は、その旨を仕様として明記し、タイマーをキャンセルする。
- タイマー満了時に再生中のメディアがない場合は、何もしない(エラー表示しない)。

### 3.7 時計ウィジェット

- ホーム画面に置ける時計ウィジェットを提供する。
- 時刻を **秒まで** 表示する(24時間表記は `H:mm:ss`、12時間表記は `午前/午後 h:mm:ss`。端末設定に従う)。秒は1秒ごとに更新する。
- 横幅が3マス以上のときは、左側に日付を2行で表示し、右側に時刻を表示する。
  - 1行目: 西暦と和暦(例: 「2026年（令和8年）」。元年は「令和元年」)
  - 2行目: 月日と曜日(例: 「11月16日 月曜日」。曜日は「月曜日」の形式で括弧は付けず、日付と曜日の間に半角空白を入れる)
  - 日付は0時に自動で更新する。
- 3マス以上では、時刻の文字は常に44spの固定サイズ。2マスのときは幅に収まるよう自動で縮む(最大44sp)。
- 横幅が2マスのときは、時刻の下に短い日付(例: 「11月16日 月曜日」)を表示する。
- 黒背景・白文字・オレンジの日付で、アプリと同じ配色にする。
- 横3マス×縦1マスを標準サイズとし、縦横にリサイズできる。横幅は最小2マスまで縮められる。サイズに応じて文字の大きさが変わる。
- タップするとアプリを開く。

## 4. 非機能要件

| 区分 | 要件 |
|---|---|
| 正確性 | 設定時刻から ±数秒以内に鳴動する。Doze・省電力モードでも鳴動する |
| 信頼性 | 端末再起動・アプリ強制終了後もアラームが失われない |
| 性能 | 一覧画面の表示は100件でも遅延なく操作できる |
| UX | iPhoneの時計アプリに近いUI(黒基調、大きな時刻表示、オレンジのアクセント) |
| アクセシビリティ | TalkBack対応(トグル・ボタンに説明ラベル)、文字サイズ拡大に追従 |
| 多言語 | 日本語(必須)。英語は将来対応可能な構成(文字列リソース化) |
| テーマ | ダークモード前提。ライトモードは任意 |
| プライバシー | 個人情報・位置情報は取得せず、データは端末内のみで保持する |

## 5. Android固有の要件・権限

| 項目 | 内容 |
|---|---|
| `SCHEDULE_EXACT_ALARM` / `USE_EXACT_ALARM` | 正確なアラーム登録のため。アラーム用途アプリは `USE_EXACT_ALARM` を宣言可能(Play審査の要件に注意) |
| `POST_NOTIFICATIONS` | Android 13以上。初回に許可を依頼。拒否時は説明を表示 |
| `USE_FULL_SCREEN_INTENT` | ロック画面でのフルスクリーン鳴動画面。Android 14以降は許可状態の確認と案内が必要 |
| `RECEIVE_BOOT_COMPLETED` | 再起動後の再スケジュール |
| `VIBRATE` | 振動 |
| `WAKE_LOCK` | 鳴動中の画面点灯・CPU維持 |
| フォアグラウンドサービス | 鳴動中の音声再生を維持するため。通知チャンネル「アラーム」(重要度: 高)を用意 |
| バッテリー最適化 | 必要に応じて除外設定の案内を表示 |
| スリープタイマー用 | 満了時の停止処理のため `AlarmManager` による正確な起動が必要。他アプリの再生制御にはメディアセッション/音声フォーカスを利用し、特別な権限を要求しない方式を優先する |

## 6. 画面一覧

1. アラーム一覧画面
2. アラーム作成・編集画面(サウンド選択含む)
3. 鳴動画面(フルスクリーン / 通知)
4. N分後タイマー画面(ナビゲーションバーのタブ。設定フォーム / 残り時間表示)
5. スリープタイマー画面(ナビゲーションバーのタブ。時間選択、実行中のカウントダウン、キャンセル)

ナビゲーションバー(下部)で「アラーム」「N分後」「スリープ」の3画面を切り替える。アラーム編集画面ではナビゲーションバーを隠す。

## 7. 想定アーキテクチャ(案)

- UI: Jetpack Compose + Material3(既存構成)
- 状態管理: StateFlow(Repository が保持)
- 永続化: SharedPreferences(JSON)。件数が増える場合は Room への移行を検討
- スケジューリング: AlarmManager + BroadcastReceiver
- 鳴動: Foreground Service(MediaPlayer/Ringtone + Vibrator)+ 鳴動用Activity
- DI: 手動 or Hilt(任意)

## 8. 受け入れ基準(抜粋)

- [ ] アラームを追加すると一覧に時刻順で表示される
- [ ] トグルOFFのアラームは鳴らない
- [ ] 画面ロック中・アプリ終了中でも設定時刻に鳴動する
- [ ] 端末再起動後も有効なアラームが鳴る
- [ ] 繰り返しなしのアラームは停止後に自動でOFFになる
- [ ] 曜日繰り返しのアラームは該当曜日にのみ鳴る
- [ ] スヌーズで設定した間隔(初期値9分)の分だけ経ってから再鳴動する
- [ ] 1分間無操作の場合は自動でスヌーズ/停止する
- [ ] アラームの編集・削除が反映され、古いスケジュールが残らない
- [ ] 通知権限・フルスクリーン通知権限が未許可の場合に案内が表示される
- [ ] N分後アラームを作成すると、N分後に鳴動する
- [ ] N分後アラームでもスヌーズのON/OFFと間隔が設定でき、ONなら設定した間隔で再鳴動する
- [ ] N分後アラームは停止後に自動で無効になる
- [ ] N分後アラームを新しく設定すると、既存のN分後アラームが置き換わる(常に1つのみ)
- [ ] N分後アラームは再起動後も確定した時刻に鳴動する
- [ ] スリープタイマーを設定すると、N分後に他アプリの音楽・動画の再生が停止する
- [ ] スリープタイマーの残り時間が表示され、途中でキャンセルできる
- [ ] スリープタイマーを新規に開始すると既存のタイマーが置き換わる

## 9. スコープ外(将来検討)

- 「睡眠 | 起床」(就寝/起床スケジュール)機能
- 音量の段階的増加(フェードイン)
- 世界時計・ストップウォッチ・汎用カウントダウンタイマー
- 時計ウィジェットの設定画面(色・サイズの変更)
- Wear OS / ウィジェット対応
- クラウド同期・バックアップ

## 10. 未決事項

- `USE_EXACT_ALARM` を使うか、`SCHEDULE_EXACT_ALARM`(ユーザー許可制)を使うか
- 全アラームを個別登録するか、次の1件のみ登録する方式にするか
- サウンドに端末の着信音以外(アプリ同梱音源)を含めるか
- 英語など多言語対応の時期
- スリープタイマーで他アプリの再生を止める方式(音声フォーカス / メディアキー送出 / 通知リスナー経由のメディアセッション制御)。動画アプリで確実に停止できるか実機検証が必要
- スリープタイマーを再起動後も継続させるか
- スリープタイマーのフェードアウトを初期バージョンに含めるか
