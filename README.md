# toki

iOS の時計アプリのようなアラームアプリ(Android / Jetpack Compose)。

## 機能

- **アラーム**
  - 時刻の昇順で一覧表示、トグルで有効/無効を切り替え、左スワイプで削除
  - ホイール式のタイムピッカー、曜日ごとの繰り返し
  - サウンド選択(試聴可・無音も可)
  - バイブレーション(6種類のパターンから選択)
  - スヌーズ(なし、または 1〜15 分)
  - スリープ中・アプリ終了中・ロック中でも鳴動(フルスクリーン表示 / ヘッドアップ通知)
- **N分後アラーム**: 「今から N 分後」に 1 回だけ鳴らす(スヌーズも設定可)
- **スリープタイマー**: N 分後に他アプリの音楽・動画の再生を停止する
- **ウィジェット**: 時計ウィジェット

詳細な仕様は [docs/alarm-requirements.md](docs/alarm-requirements.md) を参照してください。

## 動作環境

- Android 8.0 (API 26) 以上
- Android Studio と JDK(Gradle ラッパー同梱)
